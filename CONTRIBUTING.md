# Contributing to RokuDeck

<!-- SPDX-License-Identifier: GPL-3.0-or-later -->

Thank you for contributing. Please discuss substantial changes before implementation, keep
changes focused, and include verification evidence with pull requests.

Use the `dev` CMake preset for local builds and run the test suite before submitting changes.
Do not commit local device addresses, credentials, or other private test data.

All contributors are expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
