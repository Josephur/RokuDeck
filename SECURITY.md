# Security Policy

<!-- SPDX-License-Identifier: GPL-3.0-or-later -->

Once the public repository is available, report suspected vulnerabilities through GitHub's
[private vulnerability reporting form](https://github.com/Josephur/RokuDeck/security/advisories/new)
as the primary confidential route. Include reproduction details and impact where possible.

If that private form is unavailable, open a public issue containing no vulnerability details and
ask the maintainers to establish a private contact channel. Never disclose reproduction steps,
affected components, impact, logs, attachments, or any other vulnerability details in that public
issue. Continue only after the maintainers provide a private channel.
